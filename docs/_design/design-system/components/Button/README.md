# Button

Botões quadrados com rótulo em `label` caixa alta: primário em `button`, secundário com borda `control-border`, e o link de texto sublinhado, que é a ação mais usada no preset.

## Regras

- Um primário por tela. Em seções editoriais, prefira o link de texto ("Shop the latest").
- Rótulo começa com verbo e não usa "&" (requisitos).
- Altura mínima de 44px; foco com contorno de 2px em `ink`.
- Desabilitado não é só cor: muda o fundo para transparente.
- Os botões de checkout acelerado e o Follow on Shop são renderizados pela Shopify com as cores da marca, nunca reestilizados.
