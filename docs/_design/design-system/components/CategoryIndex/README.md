# CategoryIndex

Lista de coleções em imagens 4:5 coladas, cada uma com número em `ink-muted` e nome em `label` — um índice de revista, não um carrossel.

## Por que é assim

- A numeração 01–05 vem da Cénée (e aparece no print do Crafto). Dá ordem de leitura sem precisar de título de seção.
- A última posição pode levar a uma página (o guia de caimento), não só a coleções.

## Mapa Shopify

- Seção `Collection list` com setting `Style`: *Numbered index* (Moda) / *Rooms* (Móveis) / *Plain*.
- Imagem: `collection.image`, com fallback para a imagem do primeiro produto (`featured_image`, requisito).
- Bloco opcional `Page link` para o 5º item.

## Regras

- 3 a 6 itens. Mais que isso vira `Collection tabs`.
- No mobile: rolagem horizontal com 2,3 itens visíveis, para indicar que continua.
