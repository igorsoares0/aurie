# Header and footer

## Header

The header's look comes from **Theme settings › Header › Layout**. Its content is set in the **Header** section:

- **Color scheme** and **Show divider** (a line under the header).
- **Logo image** replaces the store name. **Logo width** sets its size.
- **Menu**: the main menu. Menu items with child links open a dropdown on desktop and expand in the mobile menu.
- **Customer account menu**: the links shown in the account menu when customers are signed in.
- **Store locator link**: shown as an icon in the **Centered logo, icons, menu below** layout, and in the mobile menu.
- **Show country/region selector** and **Show language selector**: shown in the mobile menu. Add more countries and languages in **Settings › Markets** and **Settings › Languages**.
- **Show collection images in mobile menu**: menu items that link to a collection show its image.

### Menu promotions

Add a **Menu promotion** block to show an image in a dropdown. In **Menu item**, type the name of the top-level menu item it belongs to, exactly as it appears in the menu. Then add an **Image**, a **Caption** and a **Link**.

### Announcement bar

The **Announcement bar** section sits above the header. Add one **Announcement** block per message.

## Footer

The **Footer** section settings:

- **Style**: **Plain** or **Card** (the footer sits on a rounded tile).
- **Show store name as wordmark**: displays the store name in large type across the footer.
- **Show country/region selector** and **Show language selector**.
- **Show Follow on Shop**: lets customers follow your store in the Shop app. Shop Pay must be turned on.
- **Show payment icons**.

Footer blocks:

| Block | What it shows |
| --- | --- |
| Email signup | A heading, a short text and the signup form. Signups are saved as customers who accept marketing. |
| Menu | The links of a menu. A menu block with no links is hidden. |
| Social media | An optional menu followed by the social links from **Theme settings › Social media**. |
| Text | A heading, text and an optional link, such as your showroom address or opening hours. |

On mobile the footer menus collapse into rows that open on tap.
