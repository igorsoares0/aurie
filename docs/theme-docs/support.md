# Support

## Contact us

Send your question through the [support form]([SUPPORT_FORM_URL]). Include:

- your store's address, such as `yourstore.myshopify.com`;
- the page and the section or setting your question is about;
- a screenshot, if it helps show the issue.

You'll get an automatic confirmation right away, and an answer within **two business days**.

## What support covers

- Questions about the theme's settings, sections and blocks.
- Help setting up features described in this documentation, such as swatches, size guides, metafields and filters.
- Bugs in the theme. We fix confirmed bugs in a theme update.

## What support doesn't cover

- Custom code, design changes or new features that aren't part of the theme.
- Changes made to the theme's code by you or a developer.
- Issues caused by third-party apps.
- Store setup outside the theme, such as payments, shipping or domains. For those, contact Shopify Support.

## Before you write

- Check the [FAQ](faq.md).
- If you changed the theme's code, try the same thing on a fresh copy of the theme from your theme library. If the issue goes away, it comes from the code changes.
- Turn off recently installed apps to see whether one of them causes the issue.

## Theme updates

When we release an update, Shopify shows it in **Online Store › Themes**. Updating adds the new version to your theme library with your settings and content; your current theme stays as it is until you publish the new one.
