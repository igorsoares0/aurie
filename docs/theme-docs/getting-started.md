# Getting started

## Install the theme

1. In the Shopify Theme Store, open the Arvel theme page and pick the preset you want: **Arvel**, **Facet** or **Sotto**.
2. Select **Try theme** to add it to your theme library without publishing it, or **Add theme** after you buy it.
3. In your admin, go to **Online Store › Themes** and select **Customize** on Arvel to open the theme editor.
4. When you're happy with it, select **Publish**.

The demo store's photos and products don't transfer when you install a preset. Image areas show placeholders until you add your own images, and sections that list products show your store's products.

## Set up the essentials

Work through this list once, in the theme editor:

1. **Logo and favicon.** Add your logo in the header section (**Logo image**). Without a logo, the store name is used. Add a favicon in **Theme settings › Favicon**.
2. **Colors and fonts.** Adjust the color schemes and fonts in **Theme settings › Colors** and **Typography**. See [Theme settings](theme-settings.md).
3. **Menus.** Create your main menu and footer menus in **Online Store › Navigation**, then pick them in the header and footer sections.
4. **Home page.** Replace the placeholder images and text in each section. Remove sections you don't need and add others from **Add section**.
5. **Product page.** Open a product in the editor and review the product blocks: variant picker, size guide, fit notes or dimensions, collapsible tabs. See [Product pages](product-pages.md).
6. **Product data.** If you want product cards to show materials or dimensions, add the metafields described in [Metafields and swatches](metafields-and-swatches.md).
7. **Filters.** Install the free **Search & Discovery** app to choose which filters appear on collection and search pages.
8. **Social links.** Add your accounts in **Theme settings › Social media**.

## Editing tips

- Every section has a **Color scheme** setting. Switch a section to a darker scheme to give it a filled background.
- Text fields that support it accept **dynamic sources**: select the database icon next to a field to show a product's metafield instead of fixed text.
- Use **Theme settings › Animations › Speed › None** if you prefer a store without motion. Visitors who ask their device to reduce motion never see animations.
